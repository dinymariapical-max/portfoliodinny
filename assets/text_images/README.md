# 📁 assets/text_images/

Folder ini khusus untuk **file gambar teks custom** buatan kamu (PNG atau SVG).

Letakkan file-file berikut di sini:

| Nama File | Dipakai Untuk |
|-----------|--------------|
| `header_portfolio.png` | Tulisan "Portfolio" di hero section |
| `header_year.png` | Tulisan "2026" di hero section |
| `section_get_to_know_me.png` | Tulisan "Get to know me" di section merah |

> Format boleh `.png` **atau** `.svg` — tapi kalau pakai `.svg` nanti perlu tambah package `flutter_svg`.
> Kalau pakai `.png`, langsung jalan tanpa package tambahan.
